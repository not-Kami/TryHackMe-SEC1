Networking Essentials: Technical Infrastructure

---

1. Dynamic Host Configuration Protocol (DHCP)

DHCP automates network configuration for hosts. Without it, each device would need manual setup (static IP).

The DORA process (4 steps):

    Discovery (Client -> Server): The client broadcasts to find a DHCP server.
    Offer (Server -> Client): The server proposes a configuration (IP, subnet mask, gateway, DNS).
    Request (Client -> Server): The client accepts the offer and requests that specific IP.
    Acknowledgment (Server -> Client): The server confirms and validates the lease (the assigned configuration/time).

---

2. Address Resolution Protocol (ARP)

ARP bridges Layer 3 (IP) and Layer 2 (MAC). An IP address alone is not enough to send a frame on a local link if you don't know the destination MAC address.

    Operation: A machine asks: "Who has IP 192.168.1.5? Tell 192.168.1.2".
    ARP Cache: IP/MAC mappings are stored temporarily in memory to avoid repeating requests.
    Security: ARP is vulnerable to ARP poisoning, where an attacker sends fake ARP replies to intercept traffic (MITM).

---

3. Network Address Translation (NAT)

NAT conserves public IPv4 addresses by allowing a private network to share a single public IP for Internet access.

    Private IP vs Public IP: Routers do not route private IP ranges (10.x.x.x, 172.16.x.x, 192.168.x.x) to the Internet.
    Translation Table: The router maintains a mapping between internal IP/port and external IP/port.
    Advantage: It adds a security/privacy layer by masking internal addressing from the outside.

---

4. Internet Control Message Protocol (ICMP)

Unlike TCP/UDP, ICMP is not used to carry user data. It is used to send control and error messages.

ICMP-based diagnostic tools:

    Ping: Uses Echo Request and Echo Reply to test reachability.
    Traceroute: Uses the IP TTL (Time To Live) field. Each router decrements TTL by 1. When TTL reaches 0, the router returns an "ICMP Time Exceeded" message, helping identify each hop.

---

5. Key Technical Terminology

    Encapsulation: Each lower layer adds its own headers (Data -> Segment -> Packet -> Frame).
    Collision Domain: A network segment where collisions can occur (bounded by switches).
    Broadcast Domain: A segment where broadcast messages are received by all hosts (bounded by routers).

---

Quick summary:

    DHCP: Automated IP configuration (DORA)
    ARP: IP-to-MAC resolution
    NAT: Public IP sharing for private networks
    ICMP: Diagnostics and error/control messages (Ping/Traceroute)
