🌐 Networking Concepts: Technical Reference
1. Reference Models (OSI vs. TCP/IP)

Networking is built on layers. Each layer has a specific function and serves the layer above it while being served by the layer below.
The OSI Model (7 Layers)

The International Organization for Standardization (ISO) developed the Open Systems Interconnection (OSI) model as a theoretical standard.

    L7 - Application: Provides services directly to user applications (HTTP, FTP, SMTP, DNS).

    L6 - Presentation: Handles data formatting, encryption, and compression (SSL/TLS, ASCII, JPEG).

    L5 - Session: Manages and terminates connections (sessions) between local and remote applications.

    L4 - Transport: Manages host-to-host communication and error recovery (TCP/UDP).

    L3 - Network: Handles logical addressing and path determination (Routing) using IP Addresses.

    L2 - Data Link: Manages physical addressing (MAC Addresses) and data framing for transmission between two nodes on the same network segment (Switches).

    L1 - Physical: Defines electrical, mechanical, and physical specifications for the transmission of raw bits over a medium (Cables, Fiber, Wi-Fi).

The TCP/IP Model (4 Layers)

The practical model used for the actual internet architecture.

    Application: Consolidates OSI layers 5, 6, and 7.

    Transport: Equivalent to OSI layer 4.

    Internet: Equivalent to OSI layer 3.

    Network Access: Consolidates OSI layers 1 and 2.

2. IP Addressing and Subnetting

    IPv4 Address: A 32-bit logical identifier (e.g., 192.168.1.1) assigned to a device on a network.

    MAC Address (Media Access Control): A unique 48-bit physical identifier burned into the Network Interface Card (NIC).

    Subnet Mask: A bitmask used to distinguish the Network ID from the Host ID within an IP address (e.g., 255.255.255.0).

    Default Gateway: The IP address of the router interface that connects the local network to other networks (the "exit" point).

    Routing: The process of moving a packet from one network to another. Routers use Routing Tables to determine the next "hop" based on the destination IP.

3. Transport Protocols: TCP vs. UDP

Layer 4 defines how data is moved across the network.
Feature	TCP (Transmission Control Protocol)	UDP (User Datagram Protocol)
Connection	Connection-oriented.	Connectionless.
Reliability	Guaranteed delivery (Error-checking/Recovery).	No guarantee (Best effort).
Mechanism	Three-way Handshake (SYN, SYN-ACK, ACK).	No handshake; data is sent immediately.
Speed	Slower (due to overhead/verification).	Faster (minimal overhead).
Use Cases	Web (HTTP), Email, SSH, File Transfer.	Streaming, VoIP, Online Gaming, DNS.
4. Ports and Sockets

    Port Number: A 16-bit identifier (0 to 65535) used to direct traffic to specific services on a host.

        Well-known Ports (0-1023): Reserved for standard services.

            21: FTP | 22: SSH | 23: Telnet | 25: SMTP | 53: DNS | 80: HTTP | 443: HTTPS.

    Socket: The combination of an IP Address and a Port Number (e.g., 10.10.10.5:443). It uniquely identifies a specific communication channel.

5. Network Interaction & Troubleshooting (CLI)

Essential tools for verifying connectivity and service availability:

    ping: Uses ICMP Echo Requests to check if a remote host is reachable and measures latency (RTT).

    traceroute (Linux) / tracert (Windows): Identifies every router (hop) a packet passes through to reach its destination. Useful for finding where a connection fails.

    telnet: A legacy protocol used to interact with remote services. In modern networking, it is primarily used to test if a specific port is open.

        Example: telnet 10.10.10.10 80 (Attempts to connect to the web service).

        Example: GET / HTTP/1.1 followed by Host: example.com (Manual HTTP request via Telnet).

Technical Summary for Notes

    Encapsulation: The process where each layer adds its own header (and sometimes a trailer) to the data received from the layer above as it moves down the stack.

    Data Units (PDU): Data is called different names at different layers: Segments (Transport), Packets (Network), Frames (Data Link), and Bits (Physical).

    Network Segment: A portion of a network where devices share the same underlying link/physical medium (typically the same LAN segment).
