🖥️ Windows Command Line (CMD): Technical Core
1. CLI Philosophy vs. GUI

    Efficiency: Tasks like finding an IP address or checking a process take seconds on a CLI, whereas a GUI requires multiple clicks and higher system resources.

    Remote Management: CMD is the lightweight standard for managing remote servers, routers, and IoT devices where a graphical interface isn't feasible.

    Automation: CMD allows the creation of Batch files (.bat) to automate repetitive sequences of commands.

2. Help and Discovery

The most important command for a beginner is the help switch.

    /?: Appending this to any command displays its manual, syntax, and available options (e.g., dir /?).

    more: A "pager" utility used to view long text files or command outputs one screen at a time.

        Usage: type longfile.txt | more or help dir | more.

3. Filesystem Operations

CMD treats the filesystem as a tree of drives (C:, D:, etc.), directories, and files.
Command	Technical Action
dir	Lists files and subdirectories. Common flags: /s (recursive), /a (hidden files).
cd	Changes directory. Use cd .. to go up one level or cd / for the root.
type	Displays the content of a text file (similar to cat in Linux).
mkdir / rmdir	Creates or removes directories.
copy / move	Duplicates or relocates files.
del	Permanently deletes files.
4. Network Diagnostics

CMD is often the first tool used in network troubleshooting and reconnaissance.

    ipconfig: Displays IPv4/IPv6 addresses, Subnet Masks, and Default Gateways.

        /all: Provides additional details like MAC addresses and DNS servers.

        /release & /renew: Forces a new DHCP IP assignment.

    ping: Sends ICMP Echo Requests to verify connectivity to a host (e.g., ping 8.8.8.8).

    tracert: Maps the path a packet takes to a destination, showing every "hop" (router) along the way.

    whoami: Returns the current logged-in user and their domain.

5. System and Process Management

    systeminfo: Generates a comprehensive report of the OS version, hardware, hotfixes (patches), and boot time.

    tasklist: Lists all running processes with their PID (Process ID) and memory usage.

    taskkill: Terminates a process.

        Syntax: taskkill /PID [ID] (e.g., taskkill /PID 1234).

    cls: Clears the command prompt screen for a clean workspace.

6. Advanced Maintenance Tools

These commands are used for deep system repair and audit:

    sfc /scannow: System File Checker. Scans and repairs corrupted Windows system files.

    chkdsk: Checks the file system and disk volumes for logical errors or bad sectors.

    driverquery: Produces a list of all installed device drivers and their properties.

Technical Summary for your Notes

    The Pipeline (|): Used to send the output of one command as the input to another (e.g., tasklist | findstr "chrome").

    Redirection (>): Saves command output to a file instead of the screen (e.g., systeminfo > sys_audit.txt).

    Living off the Land: Remember that attackers use these exact built-in tools to remain stealthy (e.g., using whoami and net user for enumeration).
